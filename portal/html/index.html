>_ SecLab

v1.0 · docker

一套跑在本地 Docker 里的安全练习环境。七个靶场覆盖 Web 漏洞、反序列化、 SSRF 协议利用、JWT 绕过、XXE 和应急响应，外加一个网络层的 ARP 欺骗实验。 全部只绑定 127.0.0.1，出不了这台机器。
