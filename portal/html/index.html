>_ SecLab

v1.0 · docker

一套跑在本地 Docker 里的安全练习环境。十四个靶场覆盖 Web 漏洞、反序列化、 SSRF 协议利用、JWT 绕过、XXE、Shiro 多版本、应急响应、沙箱逃逸， 请求重放与 AD CS 证书提权、Kerberos 票据、Log4Shell 与 Java 内存马， 外加一个网络层的 ARP 欺骗实验。 全部只绑定 127.0.0.1，出不了这台机器。

只在本地练。 这些容器里跑的是真实的漏洞代码，不要把端口暴露到公网或公司内网。 启动脚本默认绑定回环地址；改成 LAB_BIND=0.0.0.0 ./lab.sh up 会让同网段任何人都能访问，除非你清楚后果，否则别这么干。
